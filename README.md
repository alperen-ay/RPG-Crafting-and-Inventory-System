# RPG Crafting and Inventory Engine ⚔️

This project is a C# based Object-Oriented Programming (OOP) simulation that demonstrates core game mechanics such as item crafting and inventory management. 

**Kullanılan Temel C# / OOP Kavramları:**
* **Operator Overloading (+):** İki aynı nadirlikteki silahın birleştirilerek (crafting) bir üst seviye silaha dönüştürülmesi.
* **Explicit Casting:** Kılıcın içindeki detaylı hasar tiplerinin (Fiziksel, Büyü, Ateş) ezilerek tek bir `int` toplam hasara dönüştürülmesi.
* **Indexers (this[]):** Dışarıdan envanter (çanta) nesnesine dizi gibi erişim sağlanması ve eşya eklenmesi.
* **Struct & Enum:** Hasar tiplerinin ve eşya nadirliklerinin (Yaygın, Nadir, Efsanevi vb.) bellek dostu bir şekilde kategorize edilmesi.
